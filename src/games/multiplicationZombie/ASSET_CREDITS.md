# Multiplication Zombie — asset credits

The current prototype intentionally uses procedural HTML5 canvas drawings and a small
Web Audio fallback. The requested user-provided BGM is bundled for Zombie Defense,
while the game remains playable when optional media cannot load.

- User-provided BGM — `villatic_music-zombie-256804.mp3`, used as the Zombie Defense
  background track at `public/audio/villatic_music-zombie-256804.mp3`.

These are the external sources identified for a future art pass:

- OpenGameArt — **128x128 2D Zombies Spritesheet** (walk/attack frames).
- OpenGameArt — **Zombie animations** (richer animation states; keep the
  pack's required attribution if it is used).
- Kenney — **Interface Sounds** and **Impact Sounds** (UI and hit feedback).

Before adding any downloaded asset, verify the individual source page's
current licence and attribution requirements, copy the exact credit here, and
keep the asset licence file beside the imported files. The visual direction
must stay bright, cartoon, and non-gory.
