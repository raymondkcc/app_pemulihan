# Kembara Pintar map and collectible image prompts

Generate one wide 16:9 map background per theme and one separate collectible sheet per theme. The map background must use the same composition and normalized checkpoint coordinates so the web app can swap themes without moving the checkpoint markers. The collectible sheet is a separate asset and is not placed inside the map background.

## Shared map prompt

Create a cheerful children's educational board-game map in a bright 3D storybook style, viewed from a slightly elevated top-down angle, in a wide 16:9 landscape composition. Use a winding cream-coloured stepping-stone route from the lower-left start towards the upper-right finish. Reserve four clearly visible, empty, circular landing patches for checkpoint markers at these exact normalized positions: checkpoint 1 at x=29%, y=42%; checkpoint 2 at x=72%, y=43%; checkpoint 3 at x=47%, y=86%; checkpoint 4 at x=86%, y=20%. Keep the centre of every circular patch simple, flat, and free of landmarks, characters, text, signs, or decorative objects. Keep the four patches large enough for a web marker to sit on top. Use clean silhouettes, warm daylight, soft shadows, readable open routes, playful details, and a child-friendly palette for ages 6-10. No words, labels, letters, numbers, logos, UI, buttons, baked-in checkpoint icons, or confusing dead ends.
